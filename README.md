## About

Citoyen Numérique is a platform that allows people to communicate freely and securely online.
About the project

Citoyen Numérique is a platform designed to allow people to communicate freely and securely online.

The goal of the project is to provide a simple and private space for digital communication.

Access

To access the platform:

Open the website

Create an account or log in

Start chatting securely

You do not need a valid email address to create an account.

Privacy

User privacy is an important part of the project.

Emails are not required or verified

User data is not used or sold

Passwords are securely hashed

Messages sent in the chat are encrypted

The platform is designed to protect user privacy as much as possible.
